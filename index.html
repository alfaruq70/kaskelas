Panduan mengelola website

  1. Data tersimpan di cloud Supabase, jadi semua admin melihat data yang sama di perangkat mana pun.
  2. Admin baru: buat akunnya di Supabase (Authentication → Users → Add user), lalu klik Tambah Admin dan isi emailnya. Sebaiknya punya satu admin cadangan, misalnya wakil bendahara.
  3. Anggota baru: cukup isi NIM di Data Anggota. Anggota masuk dengan NIM sebagai ID dan password.
  4. Tiap ada kiriman bukti: menu Konfirmasi Bayar, cek bukti, lalu Terima atau Tolak.
  5. Bayar tunai: Pembayaran Kas, Catat Pembayaran. Pengeluaran: Transaksi Kas, lalu ＋ Nota.
  6. Akhir bulan: cetak Laporan, lalu Ekspor Data JSON sebagai arsip tambahan.
  7. Admin lupa password: reset lewat dashboard Supabase.
  8. Klik Keluar bila memakai perangkat bersama.
